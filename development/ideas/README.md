# ideas: Seeds

## 1. Purpose

The cheapest place to write a thought down about this domain. An idea here may be wrong, and that is acceptable. Ideas that concern the infrastructure as a whole go in [its ideas](https://github.com/huangwanhong-maker/The-Science-Infrastructures/tree/main/development/ideas).

## 2. Convention

- **One file per idea.** Name it `YYYY-MM-DD-slug.md`, and give it the front matter `status: seed`.
- **Promoting an idea.** Move its substance into a module, a theory note or a research question. Set the idea's status to `promoted`, and add a link to where the substance went.
- **Abandoning an idea.** Never delete it. Set its status to `abandoned`, and add one sentence saying why.
